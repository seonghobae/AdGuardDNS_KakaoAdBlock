# GitHub App Automation (Optional)

This repository uses a protected-branch ruleset on `develop` (and `main`) with
required status checks. Scheduled filter updates are generated by GitHub
Actions.

Important: Pull requests created with the default `GITHUB_TOKEN` do not trigger
other `pull_request` workflows. That can cause "bot update" PRs to be blocked by
required checks.

To make automation PRs fully self-gating (checks run + auto-merge), configure a
GitHub App and provide its credentials as repository secrets.

## Required secrets

- `AUTOMATION_APP_ID`
- `AUTOMATION_APP_PRIVATE_KEY`

These secrets are used by `.github/workflows/generate-filter.yml`.

## GitHub App setup (high level)

1. Create a GitHub App (owner: the repository owner).

2. Grant permissions:

   - Contents: Read and write
   - Pull requests: Read and write
   - Workflows: Read and write (only if you want the App to dispatch workflows)

3. Install the App on this repository.

4. Generate a private key for the App and store it as a repository secret.

## Verification

After secrets are configured, the next scheduled run should:

- create/update an `automation/kakao-filter-update` PR
- show normal PR checks (tests, CodeQL, etc.)
- auto-merge once required checks pass

If secrets are missing, automation still opens a PR but may require manual
intervention to satisfy protected-branch gates.
